About this data

Vehicle positions and service alerts come from MCTS GTFS-Realtime. Stop names, directions and planned journeys use the official GTFS timetable.

Predictions are shown only when a fresh, matched trip update is available. Scheduled times are not live predictions. A bus position alone cannot establish an arrival time.

Walking connections are optional straight-line estimates. Pedestrian paths, crossings and accessibility are not verified.

Address and place search needs an approved provider. Official stop and intersection search works without sharing your query with a new external geocoder.

How it works

MCTS GTFS / GTFS-Realtime → Python ingestion and SQLite schedules → Flask APIs → accessible web application

The interface uses JavaScript and Leaflet with OpenStreetMap tiles. Vehicle locations are reported GPS positions; schedules and reliable matched predictions remain clearly distinguished.
