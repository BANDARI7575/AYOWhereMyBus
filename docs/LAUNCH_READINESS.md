## Scope of the evidence

Backend executions include inherited regression cases, not 75 distinct product scenarios. Deterministic browser scenarios supply controlled transit/weather/community fixtures and speech/notification adapters. They do not prove native audio or push delivery. Real-GTFS journey tests use Flask and the actual imported schedule; third-party weather/tiles are isolated to keep those tests deterministic. WebKit covers the browser engine, not a physical iPhone or the user's Safari profile.

Runtime app-owned fonts and Leaflet are now served locally with their licenses; the approved cinematic design and Abhiraj Bandari creator section remain. Weather, favorites, nearby stops, live tracking, routes and planner contracts were retested. Maps still need network tiles; offline mode provides the cached shell, not invented transit service. Weather is separately labeled unavailable when its source fails or is stale.

Production preflight requires named/strong moderation credentials, privacy key, real-format support contact, approved retention, complete matching VAPID credentials, push encryption and a separate backup key. Readiness additionally requires a healthy background sender. Placeholder configuration cannot silently publish a reduced release.

Evidence is in [qa](qa/): `full-release-accessibility.json`, `full-release-live-journeys.json`, `full-release-live-feeds.json`, `full-release-timetable.json`, `full-release-performance.json`, `full-release-https.json`, `full-release-dependency-audit.json`, `image-pins.json` and `vendored-fonts.json`. Dependency snapshots are time-limited, not proof of absence of vulnerabilities. Local Python 3.14/Gunicorn was tested; the pinned Python 3.12 container must still run on the selected Linux host.
